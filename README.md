# bingo
Sorteia ou registra bingo

## URL oficial
https://filipizaum.github.io/bingo/

## Como utilizar

Segue o passo a passo para você controlar o Bingo:

🔗 Link do sistema: https://filipizaum.github.io/bingo/

Como configurar:

1️⃣ Abra a página: Abra o link no seu computador e maximize a janela do navegador.

2️⃣ Verifique o modo de sorteio: Vá na barra de ícones lá embaixo, clique no Raio (⚡) e garanta que a opção "Desabilitar sorteio aleatório" esteja marcada (assim você não irá adicionar números aleatórios acidentalmente ao clicar na grade de números).

3️⃣ Verifique o tipo de Bingo: Olhe no topo da tela. Se estiver escrito "Bingo - Linha", clique no primeiro botão da barra inferior (ícone Cruzado 🔀) para mudar para "BINGO - CARTELA CHEIA".

4️⃣ Prepare a tela do público: Clique no botão com ícone de Olho (👁️). Vai abrir uma janela extra (popup).

5️⃣ Arraste a tela do público para o projetor: Arraste essa janela nova para o seu segundo monitor (TV ou Projetor) e maximize ela lá. Essa é a tela que o pessoal vai ver. Depois de arrastar para o outro monitor, pressione F11 para fazer a tela de apresentação ficar em tela cheia.

✅ Pronto! Agora é só você digitar o número cantado no campo de texto da sua tela principal e apertar Enter. A tela da TV vai piscar e mostrar o número automaticamente!

Dicas:

Se você quiser mudar o esquema de cores, clique em Pincel (🖌) e então escolha o tema desejado (ex: Tema 2).

Para desfazer o último número que foi inserido, clique em Seta para a Esquerda (⬅️).

Para editar um número que foi inserido de forma incorreta (mesmo que não tenha sido o último número inserido), clique em Lápis (✏️) e então clique sobre a bola do número que deseja alterar.

Se quiser começar um sorteio do zero, clique na Lixeira (🗑️) e então no botão vermelho "Reiniciar".

Bom jogo! 🎱🍀
